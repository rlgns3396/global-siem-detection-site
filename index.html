Coverage built around attacker behavior

v1.0 spans identity, endpoint, network, cloud, web/API, data access, lateral movement, persistence, and software supply-chain telemetry.

Identity & Privilege

Brute-force variants, password spraying, MFA abuse, privileged changes, dormant-account misuse, and suspicious reset chains.

Network & C2

Scanning, beacon-like patterns, unusual egress, DNS anomalies, and fan-out behavior.

Endpoint & Persistence

Process ancestry, script/interpreter abuse, tampering, persistence changes, and suspicious execution context.

Web & API

Enumeration, authorization failures, token/API identity misuse, scraping, and abnormal status/method behavior.

Data & Exfiltration

Mass access, bulk exports, unusual transfer volume, first-seen destinations, and scripted SaaS access patterns.

Cloud & CI/CD

OAuth/device-code abuse, identity misuse, service-principal persistence, and software supply-chain attack chains.

Platform compatibility

Splunk® is referenced only to describe the target platform and technical compatibility of the content.

Splunk® Enterprise

Detection queries are written for Splunk search workflows and may require customer-specific index, sourcetype, macro, or data-model mapping.

CIM-aware design

Where applicable, content uses Splunk Common Information Model concepts. TA-dependent or custom fields are documented explicitly.

Environment tuning required

No third-party detection pack can be truly plug-and-play across every environment. Thresholds, allowlists, and field mappings should be reviewed before production use.
