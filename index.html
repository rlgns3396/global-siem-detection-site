Quality is a product feature

Coverage built around attacker behavior

The v1.0 roadmap spans identity, endpoint, network, cloud, web/API, data access, lateral movement, persistence, and CI/CD supply-chain telemetry.

Identity & Privilege

Brute force variants, password spraying, MFA abuse, privileged changes, dormant-account misuse, and suspicious reset chains.

Network & C2

Horizontal/vertical scanning, beacon-like patterns, unusual egress, DNS anomalies, and fan-out behavior.

Endpoint & Persistence

Process ancestry, script/interpreter abuse, tool tampering, persistence changes, and suspicious execution context.

Web & API

Enumeration, authorization failures, token/API identity misuse, scraping patterns, and abnormal status/method behavior.

Data & Exfiltration

Mass access, bulk exports, unusual transfer volume, first-seen destinations, and scripted SaaS access patterns.

Cloud & CI/CD

OAuth/device-code abuse, OIDC trust misuse, service-principal persistence, and software supply-chain attack chains.
