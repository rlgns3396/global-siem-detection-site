# Detection Engineering Pack

Public landing site for the **Detection Engineering Pack**.

The commercial v1.0 baseline contains 100 detection scenarios designed for practical SOC and detection-engineering use. The content is designed for use with Splunk® Enterprise, while the product brand remains independent from Splunk LLC.

## Product principles

- Executable SPL detection queries
- Required telemetry and field mapping
- MITRE ATT&CK mapping with rationale/version tracking
- Synthetic CSV/JSONL test data
- Positive, normal, boundary, allowlist, edge and negative testing
- False-positive and tuning guidance
- Investigation and response guidance
- Explicit validation status
- Ongoing post-launch detection updates
