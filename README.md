# Global SIEM Detection

Public landing site for **Global SIEM Detection Pack — Splunk Edition**.

The commercial v1.0 release is currently in development with a 100-scenario roadmap focused on deployable, testable SIEM detection content.

## Product principles

- Executable Splunk SPL
- Required telemetry and field mapping
- MITRE ATT&CK mapping with version tracking
- Synthetic CSV/JSONL test data
- Positive, normal, boundary, allowlist, edge and negative testing
- False-positive and tuning guidance
- Investigation and response guidance
- Explicit validation status
- Ongoing post-launch detection updates

This repository contains the **public product website only**. Commercial detection content and source material are maintained separately.
